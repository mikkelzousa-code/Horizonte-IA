Cómo escribir mejores prompts: guía con ejemplos reales.

El método RCTR explicado

RCTR son las cuatro cosas que un prompt experto define, y que uno vago deja a la suerte:

  • Rol — quién debe "actuar" el modelo (esto ajusta el vocabulario, el enfoque y el nivel de profundidad de la respuesta).
  • Contexto — la información específica de tu situación que el modelo no puede adivinar.
  • Tarea — qué quieres exactamente como resultado, no solo el tema general.
  • Restricciones — qué NO quieres, qué límites tiene (extensión, tono, formato, lo que sea).

Entre más específico seas en estas cuatro dimensiones, menos tiene que "adivinar" el modelo — y menos vueltas vas a dar para llegar a algo usable.

Ejemplo: marketing

✕ Vago "Escríbeme algo sobre marketing digital para mi negocio."
✓ Con RCTR "Actúa como estratega de marketing digital con experiencia en pymes [Rol]. Tengo una cafetería local en una ciudad mediana, presupuesto reducido [Contexto]. Dame un plan de 3 publicaciones semanales para Instagram durante un mes [Tarea]. Tono cercano, sin tecnicismos, sin estrategias de pago [Restricciones]."

Ejemplo: código

✕ Vago "Ayúdame con una función en Python para validar correos."
✓ Con RCTR "Actúa como desarrollador backend senior en Python [Rol]. Estoy construyendo un formulario de registro para un sitio con Django [Contexto]. Escribe una función que valide formato de correo y explique cada línea con un comentario [Tarea]. Sin dependencias externas, compatible con Python 3.10+ [Restricciones]."

Ejemplo: redacción

✕ Vago "Escribe una descripción de producto."
✓ Con RCTR "Actúa como copywriter de e-commerce [Rol]. Vendo mochilas para laptop hechas de material reciclado, dirigidas a estudiantes universitarios [Contexto]. Escribe una descripción de producto de máximo 80 palabras que destaque el material sustentable [Tarea]. Tono joven pero sin jerga forzada, sin signos de exclamación excesivos [Restricciones]."

Ejemplo: análisis de datos

✕ Vago "Analiza estos datos de ventas."
✓ Con RCTR "Actúa como analista de datos [Rol]. Te comparto ventas mensuales de los últimos 12 meses de una tienda de ropa [Contexto]. Identifica los 3 meses con mayor caída y una posible explicación para cada uno [Tarea]. Responde en una tabla, sin fórmulas técnicas, explicado para alguien sin experiencia en estadística [Restricciones]."

Errores comunes al escribir prompts

  • Pedir todo en una sola frase gigante. Es mejor dividir tareas complejas en pasos, y pedirle al modelo el primer paso antes de continuar.
  • No decir qué NO quieres. Si no pones restricciones, el modelo elige por ti — y no siempre acierta con lo que tenías en mente.
  • No iterar. El primer resultado casi nunca es el final. Pídele ajustes concretos ("hazlo más corto", "cambia el ejemplo 2") en vez de reescribir todo desde cero.
  • Asumir que el modelo recuerda contexto de otra conversación. Cada conversación nueva empieza en blanco — si necesitas ese contexto, tienes que dárselo otra vez.
